Corazón Olivo · Editor de alabanzas

Área de preparación de cambios · Versión 1.2

Seguridad: este editor no publica cambios por sí mismo. Los borradores se guardan únicamente en este navegador. Para actualizar el repertorio público debes descargar el catálogo y subirlo desde tu cuenta de GitHub. No ingreses contraseñas ni tokens aquí.

Selecciona una línea, modifica su texto o mueve los acordes. Usa espacios solo como referencia inicial; la ubicación definitiva se revisa con el PDF original.

Editar línea

Los botones desplazan el bloque de texto del acorde seleccionado en la línea; para ajustes exactos también puedes editar el texto directamente.

Guardar y exportar

Después de descargar el archivo, súbelo a la rama desarrollo-editor. No subas cambios directamente a main hasta verificarlos.
